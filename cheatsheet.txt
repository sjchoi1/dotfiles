VIM CHEATSHEET
══════════════════════════════════════════════════════════════════════════════

MODES                                    │ TMUX (prefix = Ctrl+b)
─────                                    │ ──────────────────────
i / a       insert before/after cursor   │ c           new window
Esc         back to normal mode          │ n / p       next/prev window
v / V       visual / visual line         │ 0-9         go to window N
                                         │ d           detach session
NAVIGATION                               │ x           kill pane
──────────                               │ %           split vertical
h j k l     left/down/up/right           │ "           split horizontal
w / b       next/prev word               │ arrow       switch pane
0 / $       line start/end               │ z           zoom pane (toggle)
gg / G      file start/end               │ [           scroll mode (q to exit)
Ctrl+d/u    page down/up                 │ ,           rename window
/text       search (n/N next/prev)       │ $           rename session
                                         │
EDITING                                  │ TMUX COMMANDS
───────                                  │ ─────────────
x           delete char                  │ tmux                new session
dd          delete line                  │ tmux ls             list sessions
yy          yank (copy) line             │ tmux a              attach last
p           paste                        │ tmux a -t name      attach to name
u           undo                         │ tmux kill-ses -t N  kill session
Ctrl+r      redo                         │
.           repeat last change           │ CUSTOM SHELL
                                         │ ────────────
COMMON COMBOS                            │ gg          git add, commit ".", push
─────────────                            │
dw          delete word                  │
cw          change word                  │
ciw         change inner word            │
di"         delete inside quotes         │
yiw         yank inner word              │
                                         │
SAVE & QUIT                              │
───────────                              │
:w          save                         │
:q          quit                         │
:wq         save and quit                │
:q!         quit without saving          │
                                         │
WINDOWS                                  │
───────                                  │

:q          close window                 │
                                         │
FILE EXPLORER                            │
─────────────                            │

-           go up directory              │

                                         │
