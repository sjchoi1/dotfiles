VIM CHEATSHEET
==============

MODES
-----
i / a       insert before/after cursor
Esc         back to normal mode
v / V       visual / visual line

NAVIGATION
----------
h j k l     left/down/up/right
w / b       next/prev word
0 / $       line start/end
gg / G      file start/end
Ctrl+d/u    page down/up
/text       search (n/N next/prev)

EDITING
-------
x           delete char
dd          delete line
yy          yank (copy) line
p           paste
u           undo
Ctrl+r      redo
.           repeat last change

COMMON COMBOS
-------------
dw          delete word
cw          change word
ciw         change inner word
di"         delete inside quotes
yiw         yank inner word

SAVE & QUIT
-----------
:w          save
:q          quit
:wq         save and quit
:q!         quit without saving

WINDOWS
-------
Tab         next window
Shift+Tab   prev window
:q          close window

FILE EXPLORER
-------------
Enter       open file
-           go up directory
%           create file
D           delete
